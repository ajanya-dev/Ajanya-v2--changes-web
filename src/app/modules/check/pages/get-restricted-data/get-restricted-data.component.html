Default Payment Processing Method

Now you can set a default payment processing method for each of your payees. Once you set a default method for a payee, the checks created for the payee can be processed with a single click.

Default Methods

Mail or Email check to payee

Print check

Direct deposit to payee

How to Setup Default Method

Contact customer support to enable feature

From Payee page, add or edit an existing payee

Select from "Default pay method" and save the payee
