@if (isFirstSection) {
1 Log into your NetSuite portal.
2 Copy the subdomain of the URL at the top of your browser and enter it below.
Your NetSuite Account ID is the combination of letters or numbers before "app.netsuite.com".
For example, if your URL is "https://123456.app.netsuite.com/app/center/card.nl?sc=-29&whence=", the value to enter is 123456.
} @else if (!isLegacyFlow) {
1 In your NetSuite account, navigate to Setup > Integration > Manage Integrations > New.
2 Give the Integration a name, then under OAuth 2.0 check AUTHORIZATION CODE GRANT and REST WEB SERVICES.
3 Enter the Redirect URI provided in the detailed instructions linked below.
4 Save the Integration.
5 You will receive a Client ID and Client Secret on the confirmation screen. Enter the values below.
} @else {
1 A NetSuite Role, Integration, and Access Token must be created to generate a Consumer Secret, Consumer Key, Token Id, and Token Secret. It is suggested you follow the linked guide with detailed descriptions of these processes!
2 To create a NetSuite Role, log into your NetSuite account and import the permissions bundle as outlined in this guide. If you elect to manually create a Role rather than using the bundle, you will need to ensure the permissions entered are correct. For an overview of the permissions, please see this guide.
3 In Manage Users, either select a user to assign the Role to or create a new user.
4 To assign the Role to the user, navigate to the user's employee record and click Edit. Navigate to the Access tab and under Roles, select the Role you just created through the prior steps.
5 To create an Integration, navigate to Setup > Integration > Manage Integrations > New.
6 In the New Integration page, populate the details outlined in this guide. Most importantly, ensure CONCURRENCY LIMIT is set to null, REST WEB SERVICES is checked, and TBA AUTHORIZATION FLOW and REDIRECT URI are populated with https://app.merge.dev/oauth/callback.
7 Save the Integration.
8 You will receive a Consumer Key and Consumer Secret at the bottom of the confirmation screen. Enter the values below.
9 To create an Access Token, go to Users/Roles then Access Tokens and select New.
10 Create a New Access Token with the User Role and Integration you just created with all the correct permissions and click Save.
11 You will receive a Token ID and Token Secret. Enter the values below.
}
